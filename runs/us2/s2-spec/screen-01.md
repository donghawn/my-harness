# screen-01 산책 모드 (리드줄 거리 감지 중)

## 목적
산책 모드 지도 위에서 에어태그로 보호자와 반려견의 거리를 계속 감지하고, 리드줄 2m 초과 경고의 누적 횟수를 상단에 상시 보여준다(PRD F-10). 하단 카드에는 시간·거리·칼로리와 목표 달성률, '산책 종료' 1개를 둔다(F-12). 이 화면이 screen-02 경고 팝업의 바탕이 된다. 근거: ref-02, ref-03, ref-04, ref-05

## 유저스토리
- #2

## 섹션
- 상단 상태 영역: 리드줄 경고 누적 횟수 칩 "리드줄 경고 0회"(F-10)와 기준 표시 "리드줄 2m 이내"
- 지도: 현위치 핀(반려견 프로필/캐릭터), 코스 선택 시 경로와 턴 안내(F-11)
- 지도 위 플로팅: 긴급 버튼(항상 노출, F-16), 현위치 버튼
- 하단 카드: 목표 문구 "목표달성까지 12분 남았어요 · 73%"와 달성률 바, 시간·거리·칼로리 3열 수치(F-12)
- 하단 CTA: '산책 종료' 1개

## 컴포넌트
- Chip
- Badge
- ActionButton
- Snackbar

## 상태
- 기본: 거리 2m 이내. 누적 경고 칩에 현재 횟수를 표시하고, 지도에 현위치와 경로를 표시한다
- 빈 화면: 산책 시작 직후 기록이 없으면 누적 경고 "0회", 시간·거리·칼로리 0, 달성률 0%로 표시한다. 자유 코스면 경로와 턴 안내 없이 현위치만 표시한다
- 오류: 에어태그 연결이 끊겨 거리를 감지할 수 없으면 Snackbar "에어태그 연결이 끊겨 리드줄 거리를 확인할 수 없어요"를 띄우고 누적 칩은 마지막 값을 유지한다. 위치 수신에 실패하면 지도에 마지막 위치를 유지하고 안내 문구를 보인다
- 위치 동의 전: 위치 수집 동의를 받기 전에는 지도·경로를 그리지 않고 위치 동의 안내만 보여준다. 동의 후에만 위치와 산책 경로를 수집한다
