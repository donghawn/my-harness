# Harness Goal (R2)

| 항목 | 내용 |
|---|---|
| 입력 (매번 달라지는 값) | 유저스토리 번호 1개 (story-service.md #1–6) |
| 사용자 | 디자이너 본인 1명. 실행자이자 승인자 |
| 범위 | story-work.md 1–7단계 전체. 5단계(시안 확정)는 AI가 대신하지 않고 사람이 승인하는 게이트로 둔다 |
| 완료 기준 | 입력한 유저스토리 1개에 대해 Figma `04_Screens` 페이지에 390×844 프레임이 2–3개 있고, 7단계 판정 스크립트의 위반이 0건이고, 사람 승인 기록이 1건 있다 |

## 완료 기준 체크 (스크립트용)
- [ ] `04_Screens` 페이지의 프레임 수가 2 이상 3 이하
- [ ] 모든 프레임이 width == 390 이고 height == 844
- [ ] 판정 스크립트의 violations == 0
- [ ] 승인 기록 파일에 입력한 유저스토리 번호의 승인 1건이 있다
